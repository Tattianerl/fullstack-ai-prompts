# 📌 Sobre

Este repositório contém **prompts organizados por modo de interação com IA**, com foco em aprendizado e desenvolvimento **Fullstack com React, Node.js e SQL**.

Os prompts ajudam a:

- entender código
- planejar sistemas
- melhorar qualidade de código
- estudar arquitetura
- simular trabalho real de desenvolvedor

---

# ▶️ Como Utilizar

1. Escolha o tipo de prompt de acordo com sua necessidade.
2. Acesse o arquivo correspondente na pasta `prompts/fullstack`.
3. Copie o conteúdo do prompt.
4. Utilize o prompt em uma IA compatível com os modos **Ask, Edit, Plan ou Study**.
5. Ajuste o prompt conforme o contexto do seu projeto ou estudo.
